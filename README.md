# WUDI project website

## Local preview

Install dependencies once:

```bash
npm install
```

Start the live development server:

```bash
npm run dev
```

Open <http://127.0.0.1:5173/>. The page updates automatically when HTML, CSS, or JavaScript files change. Keep the terminal running while previewing; press `Ctrl+C` to stop the server.

To verify the production build locally:

```bash
npm run build
npm run preview
```
